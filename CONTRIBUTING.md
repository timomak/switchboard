# Contributing

Open an issue or pull request at https://github.com/timomak/switchboard. See [AGENTS.md](AGENTS.md) for repository guidance.

Run the checks in the README that cover your change. Include a regression test for behavior changes, and run the relevant frontend tests if changing inherited Linux components. Describe the resulting behavior, validation and any remaining limitation in your pull request.

Preserve upstream attribution and compatible storage paths. Use synthetic accounts in tests and screenshots, and never include credentials or live account stores.
